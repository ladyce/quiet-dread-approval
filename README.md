A one-line code review comment that approves a pull request while carrying quiet existential dread: "LGTM. The retry loop now retries forever, which is also my retirement plan. Approved." Flat, tired-engineer voice — the laugh comes from the dread itself, not from a joke bolted onto it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.txt` (85 characters, one line). Pure Python standard library, no network, no randomness — two runs write byte-identical files.
